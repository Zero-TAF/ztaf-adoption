# ztaf-adoption

The adoption methodology for the Zero-Trust Agent Framework: the staged practice model by which an organization adopts and operates zero-trust agency — inventory, mandates, decision points, evidence, and Tough Grades.

| Field | Value |
|---|---|
| Authority | Normative for Zero-TAF adoption practice (methodology level) |
| Tier | T1 |
| Wave | W1 |
| Version | 0.1.0 |
| Status | Active |
| Licence | MIT |

## What this repository owns

- `docs/adoption-methodology.md` — the five-stage methodology (Inventory → Mandate → Instrument → Prove → Operate), roles, anti-patterns, and the first-90-days quick start.

## What this repository does not own

- The definition of Zero-TAF — [ztaf-foundations](https://github.com/Zero-TAF/ztaf-foundations).
- Normative clauses — `ztaf-spec` (Wave 2). This methodology is practice guidance; it does not issue conformance requirements.
- Maturity models — placement of the programme maturity model (this repository vs the Assessment-Models programme) is **explicitly deferred** (owner ruling, 2026-11-22) and will be decided by CR.
- Scenario playbooks and worked exemplars — Wave 6 (`ztaf-adoption` extension and `ztaf-examples`); all scenarios, including CSP-facing ones, are built from first principles inside Zero-TAF.
